Toolbelt now have 1 row (10 slots) by default. Pressing ALT+1, ALT+2, or ALT+3 will switch the hotbar pages. Currently, the maximum is only 3 pages (30 slots). If you want to change this, open the “ToolbeltSettings.xml” file and on line 13, change the value in “<PageCount value="3" />” to the number of pages you want. Later, I’ll try to add a custom settings via Mod Settings in the main menu, unless the mod author releases an update before me :D

ZZZ_LocalXUiOverlay - This is compatibility patch between CATUI and [AGF HUD Plus](https://www.nexusmods.com/7daystodie/mods/870) for players in multiplayer (example: 1 **HOST** player use CATUI and 1 player use AGF) Download link to GitHub download [HERE](https://github.com/JerryCZZ/CATUI-fix/releases/download/0.9.4/ZZZ_LocalXUiOverlay.zip)

ZZZ_CATUI\Config\items.xml - This is for skill books. Books you've read have a green icon, and unread books have the standard white one. If you don't want this, just remove it from the folder.
